# What Avo doesn't do yet

This page lists things teams have asked Avo for that it doesn't support today, each with the workaround we recommend. If you need something that isn't covered here or anywhere else in the docs, [contact us](/help/troubleshooting) and we'll help you find the best approach.

## Branches and implementation

### Mark an existing event as "to implement" for another team

An event that is already on main, and already implemented by one team, can't be marked as work for a second team that needs to implement it on the same source. [Code Changes](/data-design/branches/code-changes) only lists events the branch changes, so an event the branch leaves unchanged doesn't show up there as work to do.

**Workaround:** create a [journey](/data-design/avo-tracking-plan/journeys) for the team that is implementing, add the events they need to implement, and share the journey with them. In the journey's [Developer mode](/data-design/avo-tracking-plan/journeys#implementing-journeys), developers get the triggers and code snippets for each event.
